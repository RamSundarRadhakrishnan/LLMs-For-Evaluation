# LLMs For Evaluation

Experiments with using Large Language Models (LLMs) to evaluate student exam answers.

The project explores automated grading, feedback generation, concept identification, and detection of knowledge gaps from student responses.

## Current Status

This project is in an early experimental stage.

Currently, the repository includes:

* Pydantic models for evaluation input and output
* Sample exam questions and student answers
* A notebook that tests LLM-based evaluation and moderation between two evaluators

The project is not yet a complete application, but a working prototype for experimenting with structured LLM-based answer evaluation.
